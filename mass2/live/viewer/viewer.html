The loop in mass2-live-apply

mass2-live-apply
  1. Read new chunksTake every complete record batch appended to pulses.arrows since the last poll.
  2. Label experiment statesRe-read the state log and tag each record with the state in effect at its timestamp.
  3. Apply the recipe, per channel
  4. Write resultsOne output batch per input chunk, same rows and chunk numbers, to analyzed.arrows.
  5. Histogram good pulsesAdd each good pulse's energy to its channel and state; finished time slices are appended to histograms.arrows.
  6. Publish for the viewerRewrite the open slice, the state timeline and the counters you see at the top of this page.

↻ then wait and poll again
